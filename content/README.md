# Guía Editorial del Datapath Sales Playbook

Este directorio contiene las fichas documentales del Sales Playbook estructuradas para apoyar la venta consultiva del equipo comercial de Datapath.

## Reglas Editoriales

1. **Consistencia en la Estructura**: Todas las fichas documentales deben seguir exactamente la misma estructura de encabezados para mantener la consistencia en el proyecto.
2. **Modelo de Venta Consultiva**: El objetivo principal es guiar conversaciones de valor. No es vender de manera agresiva, sino asesorar.
3. **Descubrimiento del Perfil**: Primero se descubre el perfil (tecnología, cambio profesional, estudiante, empresarial) y la necesidad específica del prospecto antes de sugerir cualquier solución.
4. **Recomendación de Programa**: Solo se recomienda el programa académico cuando ya se ha identificado la necesidad real y el perfil del prospecto.
5. **Envío de Brochure**: El brochure o ficha técnica solo se envía cuando el cliente demuestra un interés real y específico en el programa. Evitar enviarlo de forma prematura.
6. **Presentación de Precios**: El precio se presenta después de haber generado valor, explicado el retorno de inversión (ROI) y rebatido objeciones iniciales.
7. **Modificación de Fichas**: No modificar la estructura de las fichas sin asegurar la consistencia y actualización de todo el catálogo documental del proyecto.
